# Kelimelerin Labirenti

Türkçe kelime bulmaca oyunu. 4x4/5x5 harf ızgarası, parmakla sürükleme, süreli oyun, bot rakipler, kombo, üç güç kartı ve ses efektleri.

## Web
`index.html` dosyasını tarayıcıda açın. Çevrimdışı çalışır.

## Android
Android WebView ile yerel pakete gömülü HTML oyunudur. Android SDK 35 ve JDK 17 kullanır.

GitHub Actions > Android APK ve AAB > Run workflow; ya da main'e push sonrasında Actions / Artifacts kısmından çıktı alın.

**Not:** Rakipler gerçek kişiler değil, simüle botlardır. Kelime sözlüğü yerleşiktir ve sınırlıdır. Üretim için geniş Türkçe sözlük, gerçek oyuncu sunucusu, uygulama simgesi ve sürüm imzalama anahtarı gereklidir.
